servicePipeline builds and tests a Java service with its committed Gradle wrapper.

Required: serviceName.
Optional: agentLabel (default java),
timeoutMinutes (integer 1–120, default 30), buildEnv (mapping of string values).
For file-based configuration, use deploy() with jenkins.yml instead.

The Jenkins agent needs the service's JDK. Commit an executable gradlew
and the wrapper configuration to the service repository.
Unknown settings fail before agent allocation. Failed builds stop the pipeline.
buildEnv applies only to the Verify stage and does not persist to other stages.

servicePipeline implements Checkout and Verify. Use deploy() with an image
mapping in jenkins.yml for Docker Hub image publication.
